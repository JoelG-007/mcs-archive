## Purpose

This repository is meant to be a **long-term archive of my academic work**.

It serves as a place to:

- Keep practical programs in one place
- Preserve assignment work
- Track coursework across semesters
- Revisit programs and concepts later
- Maintain a record of completed academic work
- Continue adding material as the course progresses

The repository is not intended to represent a polished software project. Some programs are practical implementations, experiments, assignment solutions, or versions created while working through a problem.
