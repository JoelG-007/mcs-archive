Changes Made to Tailor the Database for Assignment Queries:
1. Library Database
    - Added Read relationships for readers and books.
    - Added IssuedBy relationships required for the issue-count query.
    - Added a Pune-based publisher for the publisher query.

2. Song Database
    - Added song authors, artists, recording companies, and studios
      with the required relationships for the assignment queries.

3. Employee Database
    - Added employee-department relationships.
    - Added employee-skillset relationships.
    - Added project-department control relationships.

4. Movie Database
    - Added Reviewer nodes.
    - Added FOLLOWS and REVIEWED relationships.
    - Added ACTED_IN relationships required for actor/movie queries.
    - Added PRODUCED relationships required for the producer query.

5. Social Network Database
    - Added John as a Person.
    - Added birthYear property to persons for the same-birth-year query.
    - Added friendships and since properties for John.
    - Added affiliations for John.
    - Added a 2015 timeline and messages for the timeline query.
    - Added the previously missing Person, Affiliation, Timeline, and Message nodes.
